# 决斗幸存者 · Duel Survivor

游戏王主题的 3D 类吸血鬼幸存者（Survivors-like）Roguelike 网页游戏。纯前端实现，无需构建步骤；账号系统与云端进度由 WorkBuddy 云服务提供。

当前版本：**v0.4.2g**（云账号版：注册 / 登录 + 云端存档 + 云端管理后台）

## 玩法概要

- **走位**：WASD / 方向键（相对镜头方向）· 触屏虚拟摇杆
- **视角**：鼠标移动环绕旋转（按住 Alt 加速）；战斗开始指针锁定，ESC / 点击画面恢复
- **冲刺 / 跳跃**：Shift / 空格（滞空可躲开地面接触伤害）
- **抽卡**：R 从卡组抽 1 张（手牌上限 7 张）
- **弃牌**：手牌满按 R 进入弃牌模式，自选一张送入墓地再抽 1 张（Shift+1-7 或点卡面「弃」）· 开局 5 次，每升 1 级 +1 次
- **召唤 / 发动**：点击手牌或按 1-7
  - ★1-4 直接出场 · ★5-6 需 1 祭品 · ★7+ 需 2 祭品 · 三幻神需 3 祭品
  - 融合（手牌「融合」→ 选目标 → 选素材）/ 同调 / 超量 / 连接 / 仪式召唤
- **终极技**：F（能量满 + 王牌怪兽在场）
- **时间魔术师**：G —— 每 3 分钟投 1 次硬币，正面破坏全部敌人，反面破坏我方全部怪兽
- **特殊胜利**：「被封印的艾克佐迪亚」+ 左腕·右腕·左足·右足五张集齐即胜
- **效果代价**：支付基本分 / 丢弃手牌 / 解放怪兽等负面效果发动前弹出确认窗

## 特性

- 3D 立牌渲染：双层视差浮雕 + 顶点色合并 + 相机距 LOD（近 26×28 / 远 12×13 / Boss 高清 44×48）
- 卡图：`data/cardimg/` 内置 160 张真实卡图（157 张卡池 + 三幻神），缺图回落到 ygoprodeck CDN
- 3D 场景：角色、怪兽、Boss（无名的法老王）、金字塔竞技场、粒子与阴影
- 怪兽自动索敌攻击，玩家专注走位与卡组决策
- PC（键鼠）与触屏双方案，虚拟摇杆 + 自适应画质
- **云账号**：姓名 + 密码注册登录，局外进度（日元 / 卡组 / 成就）自动云同步；无网络时可「离线体验」
- **可被任意域名托管**：纯静态 + 云端走绝对地址，换成自己的域名照样登录、存档、收管理员发放（切回标签页立即补拉）

## 本地运行

纯静态站点，任选其一：

```bash
# 方式一：Python
python -m http.server 8000

# 方式二：Node
npx serve .
```

浏览器打开 `http://localhost:8000` 即可（本地启动时云库不可直连，可用「离线体验」按钮；注册 / 登录需在线上域名下使用）。

## 技术栈

- Three.js r140（UMD 本地引入，IIFE，无构建步骤）
- 原生 JavaScript / CSS3 / Canvas 2D
- WorkBuddy Cloud SDK（jsDelivr CDN）+ 云数据库 `ds_users` 表

## 用户端与管理端

| | 入口 | 用途 |
|---|---|---|
| 用户端 | `index.html` | 注册 / 登录后进入游戏；「管理员后台 →」固定指向原域名（换域名后管理端不跟着漂） |
| 管理端 | `admin.html` | 用**管理员账号**（`ds_users.is_admin = true`）登录，管理全体玩家 |

管理端能力：查看注册用户与在线情况、**发放日元**（给指定玩家加减，玩家端 15 秒内自动到账；
发放走 `data.yenSeq` 版本号，玩家端推送前会先合并，不会被本地存档覆盖）、
新建玩家账号、重置玩家密码、查看单个玩家的进度与卡牌收集。

账号数据存于云库 `ds_users`：密码仅保存 `SHA-256('ds:v1:' + 密码)` 摘要，明文不出浏览器。

## 换自己的域名

见工作区根目录的 `域名接入说明.md`：`duelsurvivor.com` 尚未注册，需先购买；DNS 就绪后加 `CNAME` 即可挂到 GitHub Pages。
**注意 `DS_PUBLIC_CONFIG.endpoint` 永远指向云端原地址**，别名域名只是入口，不能改它。

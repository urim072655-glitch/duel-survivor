# 决斗幸存者 · Duel Survivor

游戏王主题的 3D 类吸血鬼幸存者（Survivors-like）Roguelike 网页游戏。纯前端实现，无需构建、无后端依赖，打开即玩。

当前版本：**v0.4.3**

## 玩法概要

- **走位**：WASD / 方向键（相对镜头方向）· 触屏虚拟摇杆
- **视角**：鼠标移动环绕旋转（按住 Alt 加速）；战斗开始指针锁定，ESC / 点击画面恢复
- **冲刺 / 跳跃**：Shift / 空格（滞空可躲开地面接触伤害）
- **抽卡**：R 从卡组抽 1 张（手牌上限 7 张）
- **弃牌**：手牌满按 R 进入弃牌模式，自选一张送入墓地再抽 1 张（Shift+1-7 或点卡面「弃」）· 开局 5 次，每升 1 级 +1 次
- **召唤 / 发动**：点击手牌或按 1-7
  - ★1-4 直接出场 · ★5-6 需 1 祭品 · ★7+ 需 2 祭品 · 三幻神需 3 祭品
  - 融合（手牌「融合」→ 选目标 → 选素材）/ 同调 / 超量 / 连接 / 仪式召唤
- **终极技**：F（能量满 + 王牌怪兽在场）
- **时间魔术师**：G —— 每 3 分钟投 1 次硬币，正面破坏全部敌人，反面破坏我方全部怪兽
- **特殊胜利**：「被封印的艾克佐迪亚」+ 左腕·右腕·左足·右足五张集齐即胜
- **效果代价**：支付基本分 / 丢弃手牌 / 解放怪兽等负面效果发动前弹出确认窗

## 特性

- 3D 立牌渲染：双层视差浮雕 + 顶点色合并 + 相机距 LOD（近 26×28 / 远 12×13 / Boss 高清 44×48）
- 卡图全部由 Canvas 程序化绘制（无外部图片资源）
- 3D 场景：角色、怪兽、Boss（无名的法老王）、金字塔竞技场、粒子与阴影
- 怪兽自动索敌攻击，玩家专注走位与卡组决策
- PC（键鼠）与触屏双方案，虚拟摇杆 + 自适应画质

## 本地运行

纯静态站点，任选其一：

```bash
# 方式一：Python
python -m http.server 8000

# 方式二：Node
npx serve .
```

浏览器打开 `http://localhost:8000` 即可。

## 技术栈

- Three.js r140（UMD 本地引入，IIFE，无构建步骤）
- 原生 JavaScript / CSS3 / Canvas 2D
- 无框架、无打包器、无外部网络请求
